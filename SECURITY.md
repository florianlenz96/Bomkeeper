# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull
requests. Report them privately using
[GitHub's private vulnerability reporting form](https://github.com/florianlenz96/Bomkeeper/security/advisories/new).
If private vulnerability reporting is unavailable, contact the repository
owner using the contact methods on
[their GitHub profile](https://github.com/florianlenz96).

Include the affected version or commit, steps to reproduce, and potential
impact. Please allow maintainers reasonable time to investigate and prepare a
fix before making a report public.

## Supported versions

No product versions have been released yet.
