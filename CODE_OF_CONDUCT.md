# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.
Participants must treat each other with respect and must not engage in
harassment, discrimination, personal attacks, or disruptive behavior.

Maintainers may remove or edit contributions and may restrict participation
when necessary to address unacceptable behavior.

To report a conduct concern, contact the repository owner using the contact
methods on [their GitHub profile](https://github.com/florianlenz96). Do not
include sensitive details in a public issue.
